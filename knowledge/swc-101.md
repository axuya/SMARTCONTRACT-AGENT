# SWC-101: Integer Overflow and Underflow

## Definition

Integer overflow happens when an arithmetic operation produces a value larger than the maximum value of the integer type. Integer underflow happens when a subtraction produces a value smaller than the minimum value. In Solidity versions before 0.8.0, arithmetic did not automatically revert on overflow or underflow.

## Detection clues

- Arithmetic on user-controlled values without checked arithmetic.
- Token balances or allowances updated with unchecked addition or subtraction.
- Solidity compiler version below 0.8.0 without SafeMath or equivalent checks.
- An `unchecked` block around arithmetic that can receive attacker-controlled values.

## Impact

An attacker may manipulate balances, allowances, counters, or accounting variables. The impact can include unauthorized token transfers, incorrect balances, or denial of service.

## Remediation

Use Solidity 0.8.0 or newer where appropriate, use checked arithmetic, validate bounds explicitly, and avoid `unchecked` blocks unless the range proof is documented and tested.
